# Telegram News Bot

Бот для предложки новостей с модерацией.

## Возможности

- Пользователи предлагают новости с заголовком, текстом и фото
- Модерация в отдельной группе
- Публикация в канал
- Отложенная публикация (1ч, 3ч, свое время)
- Редактирование перед публикацией
- Блокировка спамеров
- Защита от флуда

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/NovaCode37/newbot.git
cd newbot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env`:
```bash
cp .env.example .env
```

4. Заполните `.env`:
- `BOT_TOKEN` - токен от @BotFather
- `MODERATION_GROUP_ID` - ID группы модерации
- `CHANNEL_ID` - ID канала для публикаций
- `ADMIN_USER_IDS` - ID админов через запятую

5. Запустите бота:
```bash
python bot.py
```

## Команды админа

- `/block <id>` - заблокировать пользователя
- `/unblock <id>` - разблокировать
- `/stats` - статистика
- `/scheduled` - отложенные публикации
- `/adminhelp` - справка

## Кнопки модерации

- **Опубликовать** - публикует в канал
- **Отклонить** - отклоняет новость
- **Редактировать** - изменить текст
- **СПАМ** - отклонить и заблокировать автора
- **1ч / 3ч / Свое время** - отложенная публикация
